# homebrew-cli

> [!WARNING]
> This tap is no longer maintained. Its only formula, `mapbox`, is the legacy Python CLI, [mapbox-cli-py](https://github.com/mapbox/mapbox-cli-py), which is archived.

The current Mapbox CLI is [mapbox/mapbox-cli](https://github.com/mapbox/mapbox-cli). Install it from [mapbox/homebrew-tap](https://github.com/mapbox/homebrew-tap):

```
brew install mapbox/tap/mapbox
```

Both formulae install a `mapbox` command. If you have the legacy one, remove it first:

```
brew uninstall mapbox/cli/mapbox
brew untap mapbox/cli
```
